# data 目录说明（运行时数据，不是源码）

本目录存放软件运行期产生的本地数据。除本 README 与 `.gitkeep` 外，其余文件默认不入库。

## 文件清单

| 文件 / 目录 | 用途 | 是否含敏感信息 | Git 状态 |
|---|---|---|---|
| `portfolio.json` | 用户持仓数据（代码、数量、成本等） | 个人数据，非密钥但属隐私 | 已忽略 |
| `ai_config.json` | 界面「AI 设置」保存的配置，含 `api_key` | **是，密钥** | 已忽略 |
| `yjb_token.json` | 养基宝扫码绑定后的登录 Token | **是，凭据** | 已忽略 |
| `cache/` | 两级缓存的磁盘兜底文件 | 否（行情快照） | 已忽略 |
| `exports/` | 服务端导出文件预留目录 | 视导出内容而定 | 已忽略 |
| `README.md` | 本说明 | 否 | 入库 |
| `.gitkeep` | 空目录占位 | 否 | 入库 |

## 安全约定（规范 v7.0 §5.6 / §12.3）

1. `ai_config.json` 与 `yjb_token.json` **严禁提交到 Git、严禁写入日志、严禁回显到前端**；
2. 界面展示 AI 配置时只返回掩码（如 `sk-****abcd`）；
3. 备份或迁移时，如需带走密钥文件，必须使用加密介质，不得放进公开归档；
4. 发现密钥泄露：立即删除对应文件、在服务商侧轮换密钥，并检查 `logs/` 是否误记。
