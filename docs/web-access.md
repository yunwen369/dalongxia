# 网页访问指南（本机 / 局域网 / 公网）

> 适用版本：v2.1.0 起。程序本质是一个本地网页应用（FastAPI 服务 + 同源前端），
> 本文说明如何在三种尺度上打开它。

## 一、三种访问形态

| 形态 | 地址示例 | 谁可以访问 | 启动方式 |
|---|---|---|---|
| 本机浏览器 | `http://127.0.0.1:6900` | 只有这台电脑 | 双击图标（默认） |
| 局域网 | `http://192.168.1.5:6900` | 同一 Wi-Fi/网段内的手机、平板、其它电脑 | `--lan` |
| 公网 | `https://xxx.trycloudflare.com` | 任何拿到网址的人（需口令） | `--public` |

三者可以叠加：`--lan --public` 同时开放局域网与公网。

## 二、本机浏览器（默认）

双击桌面图标或开始菜单「OpenBB 中文投研工作台」：

1. 后台拉起本地服务（端口 6900）；
2. 自动用系统默认浏览器打开 `http://127.0.0.1:6900`；
3. 任务栏通知区出现托盘图标，右键可「打开界面 / 打开数据目录 / 退出」。

要点：

- **关闭浏览器标签不会停止服务**，数据刷新继续；要彻底退出请用托盘「退出」。
- 再次双击图标不会重复启动服务，只会再打开一个标签页。
- 想回到原来的独立窗口形态：给快捷方式加参数 `--desktop`（`OpenBB-CN.exe --desktop`）。

## 三、局域网 / 手机访问

```bat
"%LOCALAPPDATA%\Programs\OpenBB-CN\OpenBB-CN.exe" --lan
```

或在系统环境变量里设 `OPENBB_HOST=0.0.0.0` 后正常启动。

启动后：

- 设置页 →「访问方式」卡会列出本机与局域网地址，并给出二维码；
- 手机连同一个 Wi-Fi，扫码即可打开（看到的是同一份本地数据，不是副本）；
- 首次启动 Windows 会弹防火墙提示，需勾选「专用网络」并允许，否则手机连不上。

> 安全提醒：局域网模式下同网段设备都能访问，公共 Wi-Fi（咖啡厅、酒店）不要开 `--lan`。

## 四、公网访问（临时网址）

```bat
:: 必须先设口令，未设口令时程序会拒绝启动公网模式
setx OPENBB_ACCESS_PASSWORD 你的口令
:: 重开一个命令行窗口后
"%LOCALAPPDATA%\Programs\OpenBB-CN\OpenBB-CN.exe" --public
```

流程：

1. 程序检查访问口令，未设置则弹窗中止（安全红线）；
2. 首次运行会把 `cloudflared` 下载到 `data\bin\`（约 60 MB，走国内可达的镜像）；
3. 建立 Cloudflare 快速隧道，日志与托盘菜单里出现 `https://<随机串>.trycloudflare.com`；
4. 设置页「访问方式」卡显示公网地址与二维码。

必读：

- **地址是临时的**：每次重启都会变，适合临时在外查看，不适合长期分发；
- **必须带口令访问**：首次打开会要求输入 `OPENBB_ACCESS_PASSWORD`；
- **不要公开分享**：本工具只读行情与个人数据，暴露面越小越好；
- 需要固定网址时，得自备域名并改用 Cloudflare 命名隧道（`cloudflared tunnel run --token`），
  当前版本预留了 `token` 参数但未提供界面配置。

## 五、参数速查

| 参数 | 作用 |
|---|---|
| 无参数 | 浏览器模式：起服务 + 打开默认浏览器 + 托盘 |
| `--desktop` | 内嵌窗口模式（pywebview，原行为） |
| `--lan` | 监听 0.0.0.0，开放局域网访问 |
| `--public` | 建立 Cloudflare 临时隧道（强制口令） |
| `--serve` / `--serve-only` | 纯服务模式，不开浏览器、不建托盘 |
| `--check` | 启动前自检，不建窗口、不起服务 |

## 六、常见问题

**手机打不开局域网地址？**
先确认电脑与手机在同一网段、防火墙已放行 6900，再用设置页里的二维码扫一次
（避免手输 IP 出错）。公司网络常隔离客户端，需要换到手机热点再试。

**公网地址打开是 502 / 打不开？**
隧道进程可能已退出。查看 `logs\app.log` 里的 `cloudflared` 相关记录，
确认安全软件没有拦截 `data\bin\cloudflared.exe`。

**组件下载失败？**
程序已内置 3 个下载源（两个 GitHub 代理 + 官方）。全失败时通常是网络问题，
可手动下载 `cloudflared-windows-amd64.exe` 放到 `data\bin\cloudflared.exe` 后重试。

**端口 6900 被占用？**
程序不会静默换端口。用 `netstat -ano | findstr :6900` 找到占用进程并关闭。
