| P1-06 | `index.html` 侧栏硬编码 `<div class="notice">真实数据 · 红涨综跌…Ctrl+M 切换主题</div>`，违反 §5.1「生产环境不得显示开发者内部提示」 |

| P1-11 | `pages.js:1615` 目标价三元表达式 `forecast.target_low === null ? "无数据" : ...` ——当 `caliver_note` 为空或 `target_low` 为 `undefined`（非 `null`）时显示为 `"undefined"` |

| P2-02 | `index.html` + `market.js` 市场面板直接渲染 K 线/分时 ECharts，首页与股票页与图表页三处重复 |
| P2-03 | `app.js` 刷新按钮仅调用 `loadHealth()`（刷新健康检查），不刷新当前视图数据 |
